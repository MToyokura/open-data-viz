# 比較 UI の改善

## 背景

`asset_distribution` と `workers_by_age_employment_type_education_sex` は、どちらも系列を表示・比較できるが、通常表示と属性比較で系列の作られ方が変わる。その切り替わりが画面上で明示されず、比較用の操作も複数の選択欄に分かれているため、利用者が「何を選べば比較になるのか」「今の条件のどれが比較に使われているのか」を把握しにくい。

- `asset_distribution` は、通常時に属性条件を変えると系列が追加される。比較する属性を選ぶと比較が直ちに始まり、利用可能な比較区分が自動選択される。比較軸の通常選択欄は無効になるが、その選択値は残る。比較軸以外の属性条件は各比較系列に共通して適用される。
- `workers_by_age_employment_type_education_sex` は、通常時に選択条件の系列を個別に追加する。比較属性を選ぶと、その属性以外の条件を固定した比較へ切り替わり、利用可能な区分が自動選択される。比較中に変えた固定条件は、比較終了時に保存した条件へ戻る。
- どちらも、比較属性の選択、区分の選択、表示中系列の確認が別々の場所にあり、モバイルでは条件パネルが閉じた状態から始まる。

## 目的

通常表示と属性比較を明確な別モードとして示し、切り替えたときに系列条件がどう変わるか、比較グラフがどの条件に基づくかを利用者が予測できるようにする。既存の系列・比較データと公開データ形式は変更しない。

## UI 方針

1. 条件パネル上部に二択のモード切り替えを置く。
   - **系列を追加**：属性条件を選び、条件の組み合わせを表示系列として追加する。
   - **属性を比較**：比較する属性を選び、その属性の区分を並べる。ほかの属性条件は比較系列に共通する固定条件として使う。
2. 「比較モード」の語だけに頼らず、各モードの目的を短い説明で示す。選択中のモードと表示系列の状態が視覚的にも分かるようにする。
3. モードに応じて操作欄を切り替える。比較中に通常モードの条件欄が残る場合は、比較軸が比較対象になり、残りの条件が固定条件であることを欄の近くに明示する。
4. 比較属性・区分集合を選んだときは、利用可能な区分をすべて初期選択し、「利用可能な区分を全選択しました」と系列数を表示する。2区分未満ならグラフが比較にならないことを明示する。
5. 比較する系列一覧をモード選択と近い位置に置き、現在のモード名、系列数、各系列ラベルを示す。系列削除と全消去の対象も現在のモードに対応させる。
6. モバイルでもモードと現在の状態が見つけやすいようにする。折りたたまれた条件パネルの見出し、比較系列一覧の見出しに状態を反映する。

## 共通の状態と遷移

モードは比較属性の有無とは独立して管理する。「属性を比較」には、属性未選択の状態と属性選択済みの状態がある。

| 操作・状態 | 条件と選択状態 | グラフ・系列一覧・削除操作 |
| --- | --- | --- |
| 「系列を追加」から「属性を比較」へ切り替える | 切り替え時点の通常条件を保存する。通常系列は保持し、比較用の固定条件に通常条件をコピーする。比較属性・区分集合・比較区分は未選択にする | 比較系列は0件。「比較する属性を選んでください」と表示し、通常系列は表示しない。削除・全消去は無効にする |
| 比較属性を選ぶ・変更する | ほかの属性の比較用条件を維持し、新しい属性の利用可能な区分を全選択する。区分集合がある画面では下記の集合選択規則に従う | 新しい比較系列だけを表示する。削除・全消去は比較区分だけを対象にする |
| 比較属性を未選択に戻す | 比較属性・区分集合・比較区分をクリアし、比較用の固定条件は保持する | 属性未選択時の表示に戻る。通常モードには切り替えない |
| 「属性を比較」から「系列を追加」へ戻る | 比較中の編集を終了し、保存した通常条件と保持していた通常系列を復元する。比較用状態は破棄する | 復元した通常系列を表示する。比較属性を一度も選ばなかった場合も同じ動作とする |

- 通常条件の保存はモード切り替え時に一度だけ行う。比較属性や区分集合を変更しても保存内容を上書きしない。比較を再開するときは、その時点の通常状態から新しく開始する。
- 比較中は「終了すると比較開始前の条件と系列に戻ります」と表示する。通常系列の取得中に比較へ切り替えた場合も、取得結果は保持している通常系列へ反映できるが、比較グラフには表示しない。
- 比較軸を変更すると、旧比較軸は比較用条件に保持していた単一選択値を固定条件として使う。新比較軸の単一選択値は保持するが比較には使わない。切り替え後の固定条件を欄の近くとグラフ付近に表示する。

### 固定条件変更時の比較区分

- 比較中の固定条件は、変更後に利用可能な比較区分が0件・1件になる場合も選択できる。比較に必要な系列数を満たさないことだけを理由に、固定条件の選択肢を無効にしない。
- 両画面とも、選択済み区分のうち変更後も利用可能なものを維持し、利用不可になったものは選択から解除する。新たに利用可能になった区分は自動選択しない。
- 自動解除した場合は、区分名と「共通条件の変更により選択を解除しました」を表示する。利用不可の区分は理由付きで選択不可にする。
- 固定条件を元に戻しても、解除した区分は自動復活させない。利用者が再選択する。系列削除・全消去で外した区分も同じ扱いとする。
- 利用可能な区分数と選択中の系列数を区別する。選択が0件なら区分の選択を促し、1件なら「比較には2系列以上を選択してください」と表示する。データ自体が不足する場合は、その旨を別に示す。
- 利用可能性は公表状況・系列索引に基づいて判定する。取得中・取得失敗は選択解除の理由にせず、選択を維持して取得状態と再試行操作を表示する。

### 比較系列数とグラフ表示

- 両画面とも、比較属性が未選択または比較区分の選択が0件ならグラフを描画せず、属性または区分の選択を促す。変更前のグラフは残さない。
- 比較区分の選択が1件でも、取得できた系列をグラフに表示する。「比較には2系列以上を選択してください」をグラフ付近にも表示し、1系列を確認しながら条件や区分を変更できるようにする。
- 選択数と取得成功数は区別する。2区分以上を選択していて取得成功が1件の場合は、選択不足の案内を出さず、取得中・取得失敗を表示する。取得成功した系列は表示できるようにし、未取得系列を0や欠損値に置き換えない。
- 利用可能な区分自体が2件未満の場合は、条件変更を促すデータ不足の案内を併記する。系列一覧と削除・全消去は、グラフの描画状態にかかわらず選択中の比較区分を対象にする。

## 画面ごとの動作

### `asset_distribution`

- 初期モードは「系列を追加」とし、現在の単一条件系列を表示する。
- 「属性を比較」に切り替えたら比較属性と区分集合を選ぶ。選択した集合内の区分を比較系列として表示し、他の属性は共通条件として維持する。
- 既存データの `comparison_sets` を維持する。教育の「在学中・卒業／卒業者の学歴」、所得の「年間可処分所得階級／年間可処分所得十分位階級」は別の集合として扱い、異なる集合の区分を混在させない。
- 比較属性の選択時は、利用可能な公表系列が2つ以上ある最初の集合をデータ順で初期選択する。該当する集合がなければ最初の集合を選び、比較に必要なデータが不足していると表示する。集合が1つの場合も集合名を表示する。
- 区分集合は、現在の固定条件で利用可能な公表系列が0件・1件でも選択できる。各集合には利用可能な区分数を表示する。固定条件・集合の選択可否と、個々の比較区分の公表状況による選択可否を分けて扱う。
- 集合を変更すると旧集合の区分選択を破棄し、新集合で利用可能な区分を全選択する。固定条件の変更だけでは集合を自動変更せず、前述の選択解除規則を適用する。比較属性・集合名をグラフ付近にも表示する。
- 比較中は比較軸の単一選択値を比較条件として誤認させない。軸の選択欄を隠すか、比較対象になることが明瞭な表示に切り替える。
- 比較を終了して「系列を追加」に戻ると、比較開始前の単一条件と表示系列を復元する。比較中に変更した共通条件は通常条件へ適用しない。
- 既存の公表状況により比較できない区分は選択不可とし、理由を示す。

### `workers_by_age_employment_type_education_sex`

- 初期モードは「系列を追加」とし、現在の複数系列追加の動作を維持する。
- 「属性を比較」に切り替えたら比較属性を選び、その他の条件を固定した区分比較を行う。比較中に固定条件を変えられる仕様は維持し、その条件が全比較系列に適用されると表示する。
- 比較終了時に通常モードの条件と系列一覧を復元する。既存の `normalSnapshot` の扱いをこのモード遷移に合わせて整理する。
- 条件に合う系列がない区分、比較可能な区分が1つだけの場合、系列データ取得中・取得失敗を、モードと区別できる文言で案内する。

## 受け入れ条件

- 利用者が画面を開いて、現在が「系列を追加」か「属性を比較」か判別できる。
- 比較モードで比較軸と共通条件が判別でき、比較対象の区分と表示系列の対応も分かる。
- モード切り替えで、通常系列と比較系列のどちらが追加・削除・全消去されるかが明確である。
- 比較属性を変更したとき、比較区分とグラフが新しい属性に同期する。
- 比較属性が未選択でも「属性を比較」と判別でき、通常系列が表示・削除されない。属性を選ばず通常モードへ戻っても開始前の状態が復元される。
- `asset_distribution` で教育・所得の区分集合を変更すると、集合名・区分一覧・初期選択・グラフが同期し、集合をまたぐ系列が混在しない。
- 比較軸を変更したとき、旧比較軸に適用される単一条件が固定条件として明示され、通常条件の保存内容は変わらない。
- 固定条件を変更すると、利用不可になった区分だけが理由付きで解除され、残りの選択は維持される。条件を戻しても解除した区分や削除済み区分が自動復活しない。
- 比較可能な区分が0件・1件になる固定条件や、`asset_distribution` の区分集合も選択できる。比較可能数が不足しても別の固定条件・集合へ変更でき、利用不可の比較区分は理由付きで選択不可になる。
- 比較系列が0件・1件、利用可能な区分が不足、取得中、取得失敗をそれぞれ判別できる。取得失敗によって区分選択が解除されない。
- 両画面とも比較区分の選択が0件ならグラフを描画せず、1件なら取得成功後にその系列と比較に必要な選択数の案内を表示する。2区分以上を選択して取得成功が1件の場合は、その系列と残りの取得状態を表示し、選択不足とは案内しない。
- 比較を終了したとき、通常モードの条件・系列が仕様どおり復元され、隠れた条件変更が残らない。
- 狭い画面でもモード切り替え、固定条件、比較区分、系列数を把握できる。
- 既存のデータ取得、秘匿・欠損値の表示、グラフの向き、アクセシビリティラベルを維持する。

## 実装時の確認事項

- 両画面でモードの名称、配置、開始・終了の意味を揃える。
- モードごとに選択状態を分離し、切り替えや属性変更で別モードの系列状態を誤って破棄しない。
- 比較属性・区分集合の変更時の全選択と、固定条件変更時の選択維持・解除を別の処理にし、全消去後の条件変更で意図せず再選択しない。
- 通常条件の保存・復元、比較未設定時の空表示、再入場時の初期化を両画面で揃える。遅れて完了した取得結果が別モードや変更前の比較系列を表示しないようにする。
- タッチ操作、キーボード操作、読み上げ順、選択中モードのアクセシビリティ状態を確認する。
