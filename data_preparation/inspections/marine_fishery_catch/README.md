# 海面漁業魚種別漁獲量の調査

対象は漁業・養殖業生産統計年報の「海面漁業魚種別漁獲量累年統計（全国）」です。

- [e-Stat の Excel ファイル](https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040416370&fileKind=0)
- 表の範囲: 全国、1956～2024 年
- 単位: t
- 調査時に確認したファイルサイズ: 74,858 bytes
- SHA-256: `0e057ae6dc8476837cf564f10a8039921ef9b56238d4b81e2103316bc9aced8e`

## ワークブック構造

対象シートは `Sheet1` です。`A4` は全国を示します。`A5:DH7` は系列の階層見出し（総数・小計・個別系列を含む）、8 行目は各系列の単位です。B～DH の 111 系列はすべてトンです。9～77 行が連続する 69 年分で、A 列の括弧内の西暦年を年として扱います。元の年ラベルは元号切替や末尾かなを含むため、西暦を正規表現で抽出し、表示用には元ラベルも保持します。

出力する系列 ID は列位置に基づく安定 ID とし、列、表示名、階層パス、系列種別（総数・小計・明細）の対応を明示的に管理します。行 5～7 から組み立てた見出しが対応表と違う場合は変換を失敗させ、列ずれを見逃しません。総数・小計も元表の公表値を保持し、明細の合計で再計算しません。

## 値と注記

調査したスナップショットの 7,659 個の値のうち 1,114 個は空白を伴う `…` マーカーです。空白を trim して `null` に変換します。数値のゼロはゼロとして保持し、空欄やその他の非数値は座標を付けてエラーにします。注記欄は原文を保存します。注記が対象系列・年を特定する場合は、その対応もデータに記録します。

JSON のスキーマ v2 では、各注記に原文 `text`、原資料の番号 `number`、対象系列の ID `seriesIds`、両端を含む西暦年の範囲 `yearRanges` を保存します。表全体に適用する注記の `seriesIds` と、原資料に年の指定がない注記の `yearRanges` は空配列です。画面では選択中の系列に該当する注記を比較グラフのそばに表示します。たとえば、ちだい･きだい、ちだい、きだいのいずれかを選択すると、2019 年の系列分離を説明する注記 9 を表示します。

## 再現と検証

Rust が取得・XLSX 読み取り・変換・ステージ切替を行います。XLSX のZIPメンバーはシステムの `unzip` コマンドで展開します。対象シート、全国見出し、単位、69 年、111 系列の見出し fingerprint、代表値、欠損数を検証します。取得・変換に失敗した場合は既存の有効な原本と JSON を維持します。`--transform-only` は保存済み原本から JSON のみを再生成します。

調査時の照合点: 1956 年の総数は 4,511,923 t、2024 年は 2,786,195 t。さんまは同じ年順に 327,813 t、39,335 t。みなみまぐろの 1956 年値は欠損マーカーです。期待する配列は 69 年、111 系列、1,114 個の null です。
