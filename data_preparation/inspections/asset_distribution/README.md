# 属性別純資産額階級別世帯数

## 調査対象と表の意味

- 調査: 総務省統計局「令和6年全国家計構造調査」（調査年 2024年）
- 表: 7-131-1-1「世帯人員(7区分)，世帯主の年齢階級(7区分)，世帯主の学歴(6区分)，年間可処分所得階級(11区分)・年間可処分所得十分位階級(12区分)，資産額階級(24区分)・資産額十分位階級(12区分)別世帯数（年間可処分所得はOECD新基準による）－全国」
- e-Stat 統計表ID: `0004056120`
- e-Statでの公表日: 2026-08-28
- e-Stat HTML: <https://www.e-stat.go.jp/dbview?sid=0004056120>
- 統計局の利用上の注意: <https://www.stat.go.jp/data/zenkokukakei/2024/pdf/riyou2024.pdf>
- e-Stat公式Excel（表7-131-1）: <https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040490406&fileKind=0>

統計局資料の分布指標に関する別紙3-3 (6) は資産額階級を「純資産総額（純金融資産＋住宅・宅地）」に基づくものと定義する。0およびマイナスの世帯は最低階級に含まれ、資産額不詳の世帯は平均にのみ含まれる。このため採用表は純資産総額階級を表し、等価資産額や総資産額の階級ではない。

世帯数の集計には所得資産集計用の集計用乗率を使う（同資料別紙3-3 (1)）。API値は単純な回答世帯数ではなく、乗率を使った推計世帯数である。e-Stat APIの `VALUE` には `@unit` がなく、表題と表章項目に基づき単位を「世帯」とする。

## APIで確認した分類軸

`getMetaInfo` の `CLASS_INF.CLASS_OBJ` と全件 `getStatsData` 応答のコード・名称を保存した。HTML上の軸名、全件数も一致した。地域は全国コード `00000`、時間は2024年コード `2024000000`、表章項目は「世帯数分布」コード `07-2024`。

属性軸は次の4つで、コードとラベルの対応はAPIメタデータの順序を保持する。

HTMLとの照合では、軸名と「世帯人員7区分」などの件数は一致した。一方、HTMLから抽出した項目一覧には世帯人員の「平均」が現れず6名称だけだったが、APIメタデータでは `cat05=0`「平均」を含む7区分だった。選択肢はAPI応答に基づき7区分としている。APIとHTMLで名前や表示順に関するその他の差は確認されなかった。

## 比較集合と組合せの公表状況

- `cat01` は6つの通常年齢区分を比較できる。全体の「平均」は比較集合に含めない。
- `cat02` は `[1, 2]`（在学中・卒業）または `[21, 22, 23]`（卒業者の内訳）を比較できる。APIメタデータの `@level` と `@parentCode` では21～23が「卒業」の下位区分なので、親と子を同じ比較集合に入れない。
- `cat03` は通常所得階級 `01`～`10` または十分位 `R01`～`R10` を別々に比較できる。平均、最上位再掲は含めない。
- `cat05` は6つの世帯人員区分を比較できる。平均は比較集合に含めない。
- `cat04` はグラフの金額階級軸であり、属性比較軸にはしない。

全件応答は243,432セルで、APIページは100,000、100,000、43,432セルの3ページだった。これは `7 × 6 × 23 × 36 × 7 = 243,432` と一致し、4属性軸の6,762組すべてに36区分が存在する。ページ間および全体の重複はなく、取得漏れもない。従ってこの表では属性コードの全6,762組を `published` とし、構造上非公表の組合せは確認されなかった。`-` は組合せの欠落ではなく、当該階級に該当数字がない値としてAPI行に存在する。

## 数値と記号の扱い

API応答は `@unit` を含まず、値は文字列で返る。全件の値は非負整数または公式記号 `-`、`X` だった。APIの `NOTE` は `-` を「該当数字がない」、`X` を「集計世帯数が少ないため秘匿しているもの」と説明する。今回の全件取得では通常階級に `X` はなかった。

統計局「利用上の注意」別紙4の公式凡例では、`0` は表章単位未満、`-` は該当数字なし、`X` は秘匿を表す。通常階級の6,762系列×19区分では、観測値67,273件、該当数字なし61,184件、表章単位未満21件だった。`0` は数値の0世帯として扱わず `missing` にし、公式凡例を注記する。`-` は `missing`、`X` は `suppressed` とし、いずれも数値0へ置き換えない。API応答にない記号はエラーにする。

全体属性の `cat04=00R`「平均（資産額不詳を除く）」は51,277,351世帯。通常19階級の丸め済み表示値の合計は51,277,352世帯で、1世帯の差がある。この差を補正したり、階級から全体を再計算したりせず、公式の全体値と通常階級を独立して扱う。この表は平均系列を全体に用いており、金額階級だけを分母とした割合は表示しない。

値の照合には、e-Stat公式ファイル「7-131-1」（`statInfId=000040490406`）を使用した。同ファイルの「世帯人員」区分から `平均` の列を選び、年齢 `平均`・学歴 `平均`・可処分所得 `平均` を条件として比較した。資産額のAPI分類コード `00`、`00R`、`01`、`02`、`19` は、それぞれ公式Excelで `平均` 52,688,337、`平均（資産額不詳を除く）` 51,277,351、`25万円未満` 6,533,792、`25～50万円` 732,540、`10000万円以上` 3,304,085。対応するAPI値は全て完全一致した。公式ExcelのファイルSHA-256はmanifestに記録した。

## API標本と再現性

`samples/meta_info.json` は `getMetaInfo` 応答、`samples/stats_data.json` は全件取得から抽出した実際の値レコードである。統計データ標本は総数条件と年齢35歳未満条件の各36区分を含む。標本のコード・値は実測値で、アプリケーションIDは含まない。SHA-256とAPI取得条件、ページ数、総件数は [`capture_manifest.json`](capture_manifest.json) を参照。

生成 JSON は `output/asset_distribution/asset_distribution.json`。`dimensions`、`combinations`、`items` はAPIメタデータと全件応答から整形される。再取得には `ESTAT_APP_ID` を環境に設定して `cargo run -- asset-distribution`、保存済み応答の再変換には `cargo run -- asset-distribution --transform-only` を使う。

調査年は2024年、公表日は2026-08-28。分類表示と値の再現確認はe-Stat APIの全243,432件、公式HTMLの表題・選択軸、および公式Excelの代表5値で照合した。公式平均（資産額不詳を除く）と19階級合計の丸め差も上記の通り記録する。
