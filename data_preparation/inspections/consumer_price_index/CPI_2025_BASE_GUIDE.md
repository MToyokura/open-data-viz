# 消費者物価指数（CPI）2025年基準改定とデータ分析ガイド

**確認基準日：2026年11月17日**

本資料は、総務省統計局の2025年基準改定に関する説明と、CPIを時系列・地域別に分析する際の計算方法および注意点をまとめたものです。指定のQ&Aと「2025年基準 消費者物価指数の解説」（2026年7月初版と、その後の修正・変更案内）を中心に照合しました。独自リベース等は、本資料が提案する分析上の加工です。

## 1. 2025年基準への改定と接続指数

CPIは消費構造や商品の変化を指数に反映するため、原則として5年ごとに基準改定されます。相対価格が上がった品目から安い品目へ購入の代替が起きる場合、固定ウエイトの指数には上方バイアスが生じ得ます。ただし、基準改定による変化率の差をすべてこの要因では説明できません。公式Q&AのD-4は、ウエイト効果、リセット効果、モデル式効果、品目改定効果を区別しています。

2025年基準の通常公表は2026年8月21日（全国2026年7月分）から始まり、それに先立つ8月7日に2025年1月～2026年6月分の遡及結果が提供されました。e-Statでは2020年基準の指数も2026年12月分まで引き続き提供されます。**2025年1月以降の新基準による遡及計算と、2024年12月以前の旧基準指数の接続は別の処理**です。[e-Statの移行案内](https://www.e-stat.go.jp/api/info-cat/news/httpswwwe-statgojpapiinfo-catnewscpi-info202607)

接続指数は旧基準の過去系列を新基準の指数水準につなぎ、長期の推移を見られるようにした系列です。ただし、過去の品目構成やウエイトまで2025年基準にそろえて再計算したものではありません。接続後の品目別指数を用いて上位分類を再集計するものでもありません。

- 指数の長期推移には、公式の接続指数を使います。
- 前年比・前年同月比などの公式変化率は、接続指数から独自に再計算せず、公表値を使います。特に2025年1～12月の前年同月比、2025年1月の前月比、2025年の前年比・前年度比は2020年基準で計算した値を引き継ぎます。2026年の前年同月比とは扱いが異なります。
- 寄与度を再計算する場合は、対象期間の基準、ウエイト、算出方法を確認します。

接続と変化率の根拠：[解説Ⅲ第6（冊子pp.36–39）](https://www.stat.go.jp/data/cpi/2025/kaisetsu/pdf/3-6.pdf)。

公式指数は小数第1位まで公表されます。公式変化率は端数処理前の指数から計算するため、公表指数からの再計算値とは丸めにより異なる場合があります。小数第3位までの参考値もありますが、すべての地域・系列にあるわけではありません。2025年基準では東京都区部の品目別価格指数の参考値が追加されました。参考値も端数処理前の値そのものではなく、桁数が増えても統計上の精度が高くなるわけではありません。[解説Ⅱ・7](https://www.stat.go.jp/data/cpi/2025/kaisetsu/pdf/2.pdf)、[解説Ⅲ第5・5](https://www.stat.go.jp/data/cpi/2025/kaisetsu/pdf/3-5.pdf)

## 2. 指数の計算と独自リベース

### ラスパイレス算式

CPIは消費支出に係る価格変動を対象とし、消費税など購入と一体の間接税を含みます。直接税・社会保険料や土地・住宅の購入費は対象外ですが、持家の住宅サービスは「持家の帰属家賃」として総合に含めます。通常の基本分類のウエイトは主に**二人以上の世帯**の家計調査結果を基にし、単身世帯を含む「総世帯」の指数は別系列です。[解説Ⅰ・2、3](https://www.stat.go.jp/data/cpi/2025/kaisetsu/pdf/1.pdf)

通常の公式系列は固定基準ラスパイレス型です。前年の支出割合でウエイトを毎年更新するラスパイレス連鎖基準方式の参考指数もあり、これは長期時系列のための「接続指数」とは異なります。以下は固定基準方式の説明です。概念的には次のように表せます。

\[
I_t = \frac{\sum_i I_{i,t} w_i}{\sum_i w_i}
\]

ここで、\(I_{i,t}\) は時点 \(t\) の品目別指数、\(w_i\) は基準時の品目別ウエイトです。生鮮食品では後述の月別ウエイトを用います。全国・地方・都市階級別の品目指数も、市町村の品目指数をウエイトで加重平均してから上位分類へ集計します。

価格調査では、内容量の減少など品質が変化した場合に、品質をそろえて価格を比較します。たとえば価格が同じまま内容量が減れば単位当たり価格の上昇として扱われます。家電などで性能が向上した場合も、品質調整の方法に応じて価格変化を評価します。具体的な調整方法は品目により異なります。

### 任意の年を100とする換算

分析上の独自加工として、2025年基準の指数を別の年の平均＝100へ換算できます。以下の2028年は将来年の例であり、実施には同年の通年データが必要です。

\[
I_t^{(2028=100)} = \frac{I_t^{(2025=100)}}{\overline{I}_{2028}^{(2025=100)}} \times 100
\]

分母は同じ地域・系列の公表年平均指数を使います。月別値から作る場合、生鮮食品の個別品目は単純平均ではなく月別ウエイトによる加重平均です（第3節）。

これは指数の尺度を変える操作であり、消費構造やウエイトを2028年に更新するものではありません。上位分類（例：「肉類」）は、原則として公表済みの分類指数を換算します。品目別指数をそれぞれ換算してから合算すると、公表分類指数と異なる結果になる場合があります。

資料には、たとえば次のように注記します。

> 出所：総務省統計局「2025年基準消費者物価指数」。公表指数を使用し、独自に2028年平均＝100へ換算。品目構成・ウエイトの更新は行っていない。

## 3. 地域別ウエイトと生鮮食品

### 地域別ウエイト

地域別指数には地域ごとの消費構造を反映するウエイトが設定されています。都道府県庁所在市などでは家計調査の結果を対応させ、それ以外の市町村では地方別都市階級別ウエイトを対応させます。一部品目は市町村の実態に合わせて補正し、全国等の集計には各層の二人以上の世帯数の大きさを反映する調整も加えます。単純な市町村平均ではありません。[解説Ⅲ第4・2(2)（冊子p.26）](https://www.stat.go.jp/data/cpi/2025/kaisetsu/pdf/3-4.pdf)

気候や交通事情などにより、灯油、ガソリン、鉄道運賃といった品目のウエイトが地域間で異なることがあります。具体的な大小関係は公式のウエイト表で確認してください。上位分類の地域差には、価格変化だけでなく、電気・ガス・灯油などの支出構成の違いも反映されます。したがって、地域別指数は「地域の代表的な消費構造を踏まえた物価変動」として解釈します。

### 生鮮食品の月別ウエイトと欠測

生鮮食品の品目別ウエイトには、季節的な購入数量の変動を反映した月別ウエイトが使われます。2025年基準では、品目別月別ウエイトは2024年と2025年の購入数量を用いて作成されます。一方、「生鮮魚介」「生鮮野菜」「生鮮果物」の類全体のウエイトは年間を通じて固定されます。

比較時価格が「欠」となった場合、その市町村の当該品目の指数とウエイトを計算から除外します。市町村内で品目から類へ集計する段階では、結果として類内の残る品目の類指数で代替されます。ただし、**その類から上位類へ集計する際は、欠測品目分を含む本来の類ウエイトを維持**します。全国・地方・都市階級別では先に品目指数を地域集計するため、欠測市町村を除く同一品目の地域指数で代替される形になります。価格を直接補う「比較時価格の代入」（解説Ⅲ第1）とも区別します。

衣料品などの季節調査品目で非調査月に直近の調査期間の平均指数を用いる「保合処理」は、生鮮食品の欠測処理とは別の扱いです。

生鮮食品の単月指数や前月比は、天候などによる短期的な価格変動の分析に使えます。ただし、季節性や供給要因の影響が大きいため、持続的な物価動向を判断する際は、前年同月比、複数月の推移、年平均なども併用します。

### 年平均・年度平均の例外

年平均は1～12月、年度平均は4～翌年3月を対象とします。通常は端数処理前の月別指数の単純平均ですが、**生鮮食品の各品目は月別ウエイトで加重平均**します。「生鮮野菜」など類の年平均は通常どおり単純平均です。生鮮食品の個別品目では、基準年の12か月の指数を単純平均しても100になるとは限りません。独自リベースでも、公表年平均の代わりに単純平均を使うと別の尺度になります。

月別ウエイトの根拠：[解説Ⅲ第4・2(3)（冊子pp.26–27）](https://www.stat.go.jp/data/cpi/2025/kaisetsu/pdf/3-4.pdf)。欠測・年平均の根拠：[解説Ⅲ第5・3、4（冊子p.29）](https://www.stat.go.jp/data/cpi/2025/kaisetsu/pdf/3-5.pdf)。

## 4. 比較できること・できないこと

| 比較の切り口 | 妥当性 | 解釈上の注意 |
| --- | --- | --- |
| 同一定義の単一品目の地域別時系列 | 条件付きで有効 | 地域別の価格変化を比較できる。銘柄選定、品質調整、地域集計、代入処理などの影響があるため、「純粋な価格変化率」とは断言しない。 |
| 上位分類の地域別比較（例：光熱・水道） | 条件付きで有効 | 地域別ウエイトを通じて、代表的な消費構造を踏まえた変動を比較できる。品目構成の違いも結果に含まれる。 |
| CPI指数の水準による地域間の円価格比較 | 不可 | 各地域の指数基準が同じでも、指数は基準時からの変化を表す。指数だけから実際の販売価格（円）の高低は分からない。 |
| 異なる基準年の指数の直接比較 | 不可 | 基準や算出構造が異なる。長期推移には公式の接続指数を使い、その制約を踏まえる。 |
| 生鮮食品の単月指数・前月比 | 有効だが解釈に注意 | 短期変動の分析には有用。長期傾向の判断では季節性・天候要因を考慮し、他の期間比較も併用する。 |

単一品目の比較でも、複数市町村の地域集計やモデル式内の構成比は影響し得ます。「品目別ならウエイトの影響がない」とは解釈できません。

基本分類の公表範囲にも制約があります。全国・東京都区部は品目別までありますが、地方・都市階級・その他の公表都市は原則として総合・10大費目・中分類です。各都市の単一品目CPIが一律に取得できるわけではありません。また、県庁所在市の指数を県全体の指数として扱わないようにします。[解説Ⅰ・3(1)](https://www.stat.go.jp/data/cpi/2025/kaisetsu/pdf/1.pdf)

## 5. 分析目的に応じた統計の選択

| 知りたいこと | 適した統計・方法 |
| --- | --- |
| 地域ごとの物価の変化率 | CPI。指数の基準時からの変化として読む。 |
| 地域間の価格水準差 | 消費者物価地域差指数、または小売物価統計調査の価格データ。地域差指数は対象地域・品目・基準（全国平均または対象都市平均など）を確認する。 |
| 家計が実際に支出した金額の増減 | 家計調査の名目消費支出。CPIだけでは購入数量や購入先の変化を含む支出額は測れない。 |
| 物価変動を除いた実質的な消費支出の増減 | 家計調査の名目支出を、目的に応じたCPIで実質化する。消費支出全体の実質増減率には「持家の帰属家賃を除く総合」が用いられる。費目別分析では対応する指数を確認する。 |

「持家の帰属家賃を除く総合CPI」は、帰属家賃を除いた価格変化を把握したり、家計支出を実質化したりする際に使います。それ自体が実際の現金支出額の増加を測るわけではありません。[家計調査Q&A・F-5](https://www.stat.go.jp/data/kakei/qa-1.htm)

## 6. 2025年＝100の読み方

2025年＝100は、2025年の**年平均**を100とする意味です。たとえば2026年9月の全国総合指数が102.2であっても、2025年9月から2.2％上昇したという意味ではありません。前年同月比は別に公表された変化率を参照します。

上の102.2は読み方のための仮の数値で、実際の公表結果を示していません。

地域差指数の100は時間の基準ではなく、同じ年の地域間比較の基準です。**2025年結果は、都道府県別も都市別も全国平均＝100**です。都市別は東京都区部を含む52都市が対象で、「51市平均＝100」ではありません。[2025年消費者物価地域差指数・別表2（冊子p.12）](https://www.stat.go.jp/data/kouri/kouzou/pdf/g_2025.pdf)

## 7. 系列選択・更新時の重要事項

- 基調を見る際は「生鮮食品を除く総合」等を併用します。「生鮮食品及びエネルギーを除く総合」と「食料（酒類を除く）及びエネルギーを除く総合」は対象が異なります。コア・コアコアという通称だけで選ばず、正式名称を明示します。[公式Q&A・A-5](https://www.stat.go.jp/data/cpi/4-1.html)
- 足元の前月比較には、公表されている系列では季節調整済指数も利用できます。固定基準方式では全国・東京都区部の総合、生鮮食品を除く総合、生鮮食品及びエネルギーを除く総合、財、サービスの5系列です。すべての品目・都市にあるわけではありません。前年同月比は1年前の値動きにも左右されます。
- 2025年基準の季節調整はX-13ARIMA-SEATSを使用し、年次更新時には2010年1月以降の過去値も改定します。取得日・原系列か季節調整済みかを記録します。[解説Ⅲ第7（冊子pp.40–41）](https://www.stat.go.jp/data/cpi/2025/kaisetsu/pdf/3-7.pdf)
- 品目数は589（19品目追加、11品目廃止、2品目を1品目に統合）です。四半期指数と世帯主の住居の所有関係別指数は公表を終了しました。旧基準との結合では名称だけに頼らず、類・品目対応表を確認します。[解説Ⅱ・4、7](https://www.stat.go.jp/data/cpi/2025/kaisetsu/pdf/2.pdf)
- e-Stat APIでは統計表IDと品目分類等が変更されています。移行案内に掲載の2025年基準の統計表IDは`0004052037`です。取得処理は地域・分類コードのメタデータも確認し、基準の異なるデータを混在させないようにします。[e-Statの移行案内](https://www.e-stat.go.jp/api/info-cat/news/httpswwwe-statgojpapiinfo-catnewscpi-info202607)
- 解説の一括PDFは初版なので、利用時は目次ページの修正案内も確認します。確認日時点では2026年10月の一部修正と、2026年9月分以降適用のテーマパーク入場料の計算方法変更が別掲されています。[解説・目次](https://www.stat.go.jp/data/cpi/2025/kaisetsu/index.html)

## 結論

CPIは価格の変化を測る指標であり、地域間の価格水準差や家計の実支出額を直接表すものではありません。分析では、**価格変化率を測るCPI、地域間の価格水準差を測る地域差指数、実際の支出額を測る家計調査**を区別します。

長期比較では接続指数の性質を理解し、公式変化率と独自再計算を混同しないことが重要です。地域比較ではウエイトと調査方法、生鮮食品では季節性と欠測処理を確認してください。
